# Practical 3: Relationships and Probability

6COM2005 Data Mining and Visualisation

## Aims
- Calculate covariance and correlation by hand in Python and with pandas.
- Draw and read a correlation matrix.
- Calculate conditional probabilities from a table and check Bayes' theorem.
- Build a one-feature Gaussian Naive Bayes classifier yourself.
- Train and evaluate scikit-learn's Gaussian Naive Bayes.

## Files
- `Practical_3_T.ipynb`: the notebook you complete
- `6COM2005_DMV_Practical_3.docx`: the handout with all tasks
- `penguins.csv`: Palmer Penguins, 344 penguins, 8 attributes
